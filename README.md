## Featured project

### [PulsePlan](https://github.com/ahsanrehmat1/PulsePlan)

PulsePlan creates daily and weekly workouts from a user's goals, experience,
equipment, schedule, workout style, and movement preferences. The current build
includes:

- Email/password and Google authentication
- Offline-first Firestore synchronization and cross-device restoration
- Personalized onboarding and deterministic workout generation
- DataStore persistence and WorkManager reminders
- Active workout sessions, progress history, trends, and personal bests
- Crashlytics reporting plus in-app account and data deletion

**Built with:** Kotlin | Jetpack Compose | Material 3 | Firebase | DataStore |
WorkManager
